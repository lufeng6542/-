# 剪辑大师 - 高燃卡点视频剪辑工作流

## 触发方式
用户输入 "剪辑大师" 时自动激活此工作流

## 项目信息
- **项目路径**: D:\海贼王剪辑项目
- **素材库**: E:\海贼王临时素材库
- **BGM库**: D:\海贼王剪辑项目\BGM
- **输出目录**: D:\海贼王剪辑项目\输出

## 核心功能模块

### 1. 素材分析
- 自动扫描素材库
- 获取视频时长信息
- 按爆点潜力评级

### 2. 剪辑方案生成
- 根据抖音算法逻辑设计
- 开场3秒强钩子
- 每3秒至少一个视觉爆点
- 高潮连续上升曲线

### 3. 视频分割
- 按预设方案提取片段
- 自动转为竖屏格式 (1080x1920)
- 支持0.3-2秒的快切片段

### 4. 节奏配乐
- BGM节拍分析
- 自动匹配视频节奏点
- 淡入淡出处理

## 剪辑标准规范

### 视频定位
- 类型: 动漫打斗混剪
- 风格: 高燃/热血/爆发感强
- 时长: 15-30秒
- 比例: 9:16 竖屏

### 剪辑核心要求

#### 1. 开头3秒冲击
- 直接使用最强攻击镜头
- 角色怒吼+技能爆发
- 禁止铺垫

#### 2. 节奏设计
- 根据BGM节拍硬卡点
- 攻击动作卡在鼓点或重拍
- 爆发瞬间加0.1秒闪白或震动
- 连续攻击快切(0.3-0.5秒)

#### 3. 爆点密度
- 每3秒至少一个视觉爆点
- 技能释放、表情特写、镜头拉近、能量爆发

#### 4. 镜头优先级
- 技能释放 > 面部特写 > 武器碰撞 > 爆炸画面
- 删除拖沓对话镜头
- 删除低情绪铺垫段

#### 5. 情绪曲线
- 开头即高能
- 中段连续上升
- 结尾大招收尾
- 最后一帧保留冲击画面0.5秒

### 字幕风格
- 仅保留战斗关键台词
- 关键词放大
- 粗体白字黑边
- 每句不超过12字

## 使用流程

当用户输入"剪辑大师"时，执行以下步骤：

1. **确认素材路径**
   - 检查素材库是否有素材
   - 如有新素材路径，更新配置

2. **分析素材**
   - 获取所有视频时长
   - 按内容类型分类
   - 评估爆点潜力

3. **生成剪辑方案**
   - 根据素材特点设计节奏
   - 输出分段时长建议
   - 提供爆点强化建议

4. **执行剪辑**
   - 运行 high_energy_editor.py
   - 生成无BGM版本

5. **配乐处理**
   - 用户选择或推荐BGM
   - 运行 bgm_matcher.py
   - 生成最终配乐版

6. **输出结果**
   - 显示输出文件路径
   - 提供文件信息

## 配置文件
- 主配置: D:\海贼王剪辑项目\config\settings.py
- 素材评级: 可在脚本中自定义 EDIT_PLAN

## 注意事项
- 确保FFmpeg已正确配置
- 素材格式支持: mp4, mkv, avi, mov
- BGM格式支持: mp3, wav, m4a, flac
- 输出为H.264编码，AAC音频
